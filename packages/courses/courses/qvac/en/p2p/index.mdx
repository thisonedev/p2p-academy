Now that we've covered how each model type works, we're going to look at how the models get to your machine.

QVAC pulls model files from a peer-to-peer Hyperdrive instead of a single CDN, so downloads can come from whoever already has the file and can serve as a seeder. This chapter covers the patterns you'll use most often: pre-downloading a model, configuring blind relays for NAT traversal, and pre-downloading several models in parallel. The last two lessons move to inference: one machine serves its devices over RPC, and another loads a model across them.
