`assessModelFit()` estimated the fit before anything was downloaded. Right before it loads a model, the SDK also runs a second check on its own.

This one reads the model file already on disk and projects whether it fits in device memory with the exact settings you passed to `loadModel()`.

The check returns `fit`, `does-not-fit` or `unknown`, without the `likely-` prefix that `assessModelFit()` uses. What the SDK does with that result depends on the `modelFitPolicy` option:

- `'log'` - the default. After a `does-not-fit` result, the SDK only logs a warning and keeps loading the model;
- `'refuse'` - the SDK doesn't load the model after `does-not-fit` and throws a `MODEL_FIT_REFUSED` error;
- `'off'` - the check doesn't run, so the SDK logs no fit line.

An `unknown` result never stops the model from loading, even under `'refuse'`. It means the check had no evidence, for example when it timed out or doesn't support that kind of model.

`loadModel()` still resolves to the `modelId` alone. The SDK writes the result to a log stream, which you read with `loggingStream()` and the `SDK_LOG_ID` constant. `getLoadedModelInfo({ modelId })` also returns it in the `fitProbe` field.

Start watching the stream first, so the watcher is already running when the fit line appears:

```ts
void (async () => {
  for await (const log of loggingStream({ id: SDK_LOG_ID })) {
    if (log.message.includes("[advisory-fit:")) {
      console.log(`▸ Fit check: ${log.message}`);
    }
  }
})().catch(() => {});
```

Other SDK messages share the stream, so the `includes()` filter keeps only the fit verdicts.

With the watcher running, load the model from the first lesson without passing `modelFitPolicy`:

```ts
const modelId = await loadModel({ modelSrc: LLAMA_3_2_1B_INST_Q4_0 });
console.log(`▸ Model loaded: ${modelId}`);
```

The check can take up to 30 seconds before it gives up with `unknown`. The open log stream also keeps the process alive, so the starting file ends with `process.exit(0)`.

> Note: `modelFitPolicy` can also go in the SDK config file (`qvac.config.json`, `qvac.config.js` or `qvac.config.ts`), where it applies to every model you load. A `modelFitPolicy` passed to `loadModel()` overrides it for that model.
