A cover re-renders the whole track under a single caption. It can't restyle a song, then rewrite ten seconds of it, and it can't leave part of the clip alone.

For these cases, the SDK has a separate function: `audioEdit()`. It takes the loaded `modelId`, a `sourceAudio` file and an `operations` array that lists the changes in order.

A `flow-edit` restyles the whole clip. You describe the change with two captions:

- `from` says what the source sounds like now;
- `to` says what it should sound like.

A `repaint` regenerates the audio between `start` and `end` against its own caption. Both values are in seconds. `mode` sets how strictly the repaint preserves everything outside that range, and `strength` tunes the default `balanced` mode.

The first operation uses `seed` as given. Every later entry in the array adds its position, so the `repaint` at index 1 uses `seed + 1`.

The starting file sets `REPAINT_START` to 10 and `REPAINT_END` to 20. This exercise turns the lo-fi loop into pop-rock, then paints a synth solo over that window:

```ts
const run = audioEdit({
  modelId,
  sourceAudio: sourcePath,
  operations: [
    {
      type: "flow-edit",
      from: { caption: fromCaption },
      to: { caption: toCaption },
    },
    {
      type: "repaint",
      caption: "Analog synth solo",
      lyrics: "[Instrumental]",
      start: REPAINT_START,
      end: REPAINT_END,
      mode: "balanced",
      strength: 0.5,
    },
  ],
  seed: 22883,
});
```

Like `audioGen()`, `audioEdit()` returns a `progressStream`, `audio` and `stats`, so the rest follows the cover lesson. Drain the progress ticks, resolve the audio, and save it:

```ts
for await (const progress of run.progressStream) {
  console.log(`▸ ${progress.stage}: ${progress.step}/${progress.total}`);
}

const [audio, stats] = await Promise.all([run.audio, run.stats]);
const wav = createWav(audio.pcm, audio.sampleRate, audio.channels, audio.bitsPerSample);
writeFileSync("output/music-generation/audiogen-edit-output.wav", wav);

if (stats) console.log(`▸ Stats: ${JSON.stringify(stats)}`);
console.log(`▸ Saved output/music-generation/audiogen-edit-output.wav`);
```

> Note: `flow-edit` needs a turbo DiT variant, so the load keeps `AUDIOGEN_ACESTEP_V15_TURBO_Q4_K_M`. A `repaint` accepts any variant, but its range has to fit inside the source. The lo-fi loop is 40 seconds long, so the window from 10 to 20 fits. The SDK rejects a `start` past that length.
