Now that we've decoded neural signals, we're going to learn to control a robot. For that, we'll use vision-language-action models, or VLA for short.

VLA takes a camera frame and a task description and produces an action chunk. The chunk covers the next `chunkSize` timesteps. Each timestep is an `actionDim`-dimensional action vector the robot's actuators consume.

The SDK includes three families, all trained on a wide range of manipulation tasks:

- SmolVLA - small and fast; 
- π₀.₅ - larger and more capable;
- GR00T - uses patch-based images and switchable robot configurations.

All three use the same `vla()` function.
