On a Mac, Parakeet doesn't have to run every stage on the ggml backend. The macOS build of the transcription engine can run a model's encoder on Apple Core ML (the Neural Engine), while the mel preprocessing and the decoder stay on ggml.

The Core ML encoder is a separate set of files called a sidecar: a compiled `.mlmodelc` bundle that sits next to the GGUF. When a model loads, the engine looks for that bundle by name. It uses the bundle if it finds one and runs the encoder on ggml if it doesn't.

For a registry model, the SDK stages the sidecar itself. On macOS, loading a supported Parakeet constant also downloads its Core ML bundle and places it beside the GGUF.

In this lesson, we'll use Parakeet Unified, an English-only model that serves batch and streaming transcription from one checkpoint. The editor prefills a guard that throws `Core ML requires macOS` on any other system, so the load step looks like this:

```ts
const modelId = await loadModel({
  modelSrc: PARAKEET_UNIFIED_0_6B_Q4_0,
  modelType: "parakeet-transcription",
  modelConfig: { useGPU: true },
});
```

`useGPU: true` enables the GPU backend of ggml. The Q4 GGUF is 395 MB, and the sidecar adds 461 MB to the first download.

To see what the SDK placed in its cache, read the model's files from `getModelInfo()` as follows:

```ts
const info = await getModelInfo({ name: "PARAKEET_UNIFIED_0_6B_Q4_0" });
for (const file of info.cacheFiles) console.log(`▸ ${file.filename}`);
```

The list has the GGUF and five files under `parakeet-unified-en-0.6b-encoder.mlmodelc`. The bundle is named after the GGUF without its quantization suffix, so one sidecar serves every precision of the checkpoint.

Transcription needs no Core ML option. The source example also throws an error when the result is empty:

```ts
const text = await transcribe({
  modelId,
  audioChunk: "./examples/qvac/transcription/input/sample-16khz.wav",
});
if (!text.trim()) throw new Error("Parakeet Unified returned an empty transcription");
console.log(text);
```

Core ML covers batch transcription only for this model. Streaming with Unified goes through a cache-aware encoder, which runs on ggml.

> Note: A GGUF loaded from your own path gets no automatic sidecar. The source example covers that case: it fetches the five Core ML files with `getModelInfo()` and `downloadAsset()`, then links them into `parakeet-unified-en-0.6b-encoder.mlmodelc` beside the GGUF.
