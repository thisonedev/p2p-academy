In this lesson, we're going to transcribe one recording in English and then in Spanish, using a Whisper model called `WHISPER_TINY`. We switch the language between the two runs without unloading the model.

For this, `loadModel()` has another form, which the SDK calls a hot config reload. Instead of a `modelSrc`, we pass the ID of a model that is already loaded. `loadModel()` then changes that model's configuration.

The code first sets up the model with `language: "en"` and transcribes the recording in English. `language` takes an ISO 639-1 code, or `'auto'` to detect the language. To switch to Spanish after the first transcription, we pass three fields to `loadModel()`:

- `modelId` - the model's ID;
- `modelType` - the model's type, which has to match the type it was loaded with;
- `modelConfig` - only the fields we want to change.

The SDK merges those fields into the model's current configuration. Every field we leave out keeps its value.

To get Spanish text from the next run, we set `language` to `"es"`:

```ts
const reloadedId = await loadModel({
  modelId,
  modelType: "whispercpp-transcription",
  modelConfig: {
    language: "es",
  },
});
console.log(`▸ Config reloaded, same model ID: ${reloadedId === modelId}`);
```

Whisper applies the new `language` in place. The model keeps its ID, which the comparison confirms by logging `true`.

With Spanish set, we transcribe the recording again:

```ts
const spanishText = await transcribe({ modelId, audioChunk: audioFilePath });
console.log(`Transcription (ES): ${spanishText}`);
```

The transcript of the English recording is now in Spanish.

> Note: The reload form accepts only the Whisper model types, `"whispercpp-transcription"` and its alias `"whisper"`.
