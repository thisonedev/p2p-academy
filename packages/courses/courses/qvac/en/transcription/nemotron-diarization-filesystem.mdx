In this lesson, we're going to find out who speaks when in a recording, using a model called Nemotron 3 Diarization.

It can tell apart as many as eight voices, even when their speech overlaps. Its output covers speaker activity and leaves out the words.

Nemotron runs on the Parakeet engine, which we select with `modelType: "parakeet-transcription"`. The engine then reads the GGUF file's metadata and detects that it holds a diarization model.

The Q8_0 file is about 107 MB. `modelConfig` takes two settings for the hardware:

- `maxThreads` - sets the number of CPU threads. It defaults to 4, and 0 uses the hardware concurrency.
- `useGPU` - turns on the ggml GPU backend. It defaults to `false`.

`modelConfig` also takes two diarization settings. We leave both out, which keeps the model's defaults:

- `diarizationThreshold` - the speaker-activity threshold, from 0 to 1. Nemotron's default is 0.5.
- `diarizationMinSegmentMs` - the shortest turn in milliseconds. Nemotron's default is 200.

We point `modelSrc` at the Q8_0 file and run Nemotron on four CPU threads:

```ts
const modelId = await loadModel({
  modelSrc: PARAKEET_NEMOTRON_3_DIARIZATION_Q8_0,
  modelType: "parakeet-transcription",
  modelConfig: {
    maxThreads: 4,
    useGPU: false,
  },
});
```

Diarization uses the same `transcribe()` function as speech-to-text. With `metadata: true`, it resolves to an array of segments instead of one string.

Each segment can have a `speakerSegments` array with the turns Nemotron found. We collect the turns from every segment into one list as follows:

```ts
const segments = await transcribe({ modelId, audioChunk: audioFilePath, metadata: true });
const turns = segments.flatMap((segment) => segment.speakerSegments ?? []);
```

Each turn has a zero-based `speakerId` from 0 to 7 and a time range in `startMs` and `endMs`. Turns can overlap. To number the speakers from 1, the loop prints `speakerId + 1`:

```ts
for (const turn of turns) {
  console.log(
    `[${(turn.startMs / 1000).toFixed(2)}s → ${(turn.endMs / 1000).toFixed(2)}s] Speaker ${turn.speakerId + 1}`,
  );
}
if (turns.length === 0) console.log("▸ No speaker turns returned.");
```

> Note: Nemotron also diarizes a live stream with `transcribeStream()`. For that, set `streaming: true` in `modelConfig` before the stream starts.
