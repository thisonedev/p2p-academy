In this lesson, we're going to transcribe an audio file with Parakeet Nemotron. SDK 0.20 added Nemotron as another `parakeet-transcription` model, with a 0.6B checkpoint in three precisions.

Unlike TDT, Nemotron takes a locale in `modelConfig.language`. You can pass an alias such as `en-US` or `hi-IN`, or `auto`. The rest of the setup matches the TDT lesson:

```ts
const modelId = await loadModel({
  modelSrc: PARAKEET_NEMOTRON_0_6B_Q4_0,
  modelType: "parakeet-transcription",
  modelConfig: { language: "auto" },
});
```

The Q4 checkpoint stores its weights at the lowest precision of the three, which keeps the download to about 405 MB.

Nemotron also has a `streaming` setting. It stays at its default of `false`, so `transcribe()` runs in batch mode and resolves to the full text of the file:

```ts
const text = await transcribe({
  modelId,
  audioChunk: "./examples/qvac/transcription/input/sample-16khz.wav",
});
console.log(`▸ Transcript: ${text}`);
```

> Note: Nemotron can stream too, from the same checkpoint. Load it with `streaming: true` and feed the audio through `transcribeStream()`. The chunk size defaults to 320 ms, and `streamingChunkMs` also accepts 80, 160, 560 or 1120 ms.
