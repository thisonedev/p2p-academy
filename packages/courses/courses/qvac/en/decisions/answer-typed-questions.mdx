In this first lesson, we're going to sort a customer support ticket by asking three questions about it, using a model called Laya.

Laya doesn't generate text. For each question, it runs one forward pass and returns a probability for every option.

Laya runs with the model type `llamacpp-decision`. The registry has three Laya models, each in F16 and Q8_0. We use `LAYA_MULTILINGUAL_322M_Q8_0`, a file of about 348 MB. `modelConfig` takes a `device` setting, which defaults to `"gpu"`.

To keep the run on the CPU, we set `device: "cpu"`:

```ts
const modelId = await loadModel({
  modelSrc: LAYA_MULTILINGUAL_322M_Q8_0,
  modelType: "llamacpp-decision",
  modelConfig: { device: "cpu" },
});
```

A function called `decide()` takes the ticket text as `state`, along with a `questions` object of named entries. Each entry has a `type` and `instructions`, and the `type` is one of these:

- `choice` - picks one label from `criteria`. The answer has the `choice` and a probability per label.
- `score` - estimates a level from `criteria`, a list ordered from lowest to highest. The answer has the expected `score`, a `legend` and probabilities.
- `noul` - estimates the probability that the statement in `instructions` is true. The answer has that probability in `noul`.

Our ticket gets one question of each type, and we log the whole result as JSON:

```ts
const result = await decide({
  modelId,
  state: "My payment failed twice and I was charged both times. Please refund the duplicate.",
  questions: {
    department: {
      type: "choice",
      instructions: "Which team should handle this ticket?",
      criteria: ["billing", "technical"],
    },
    urgency: {
      type: "score",
      instructions: "How urgent is this?",
      criteria: ["not urgent", "somewhat urgent", "very urgent"],
    },
    refund: { type: "noul", instructions: "The customer asks for a refund." },
  },
});
console.log(JSON.stringify(result, null, 2));
```

`result.answers` holds one answer per question ID, and each one also includes confidence values. `result.usage` reports token counts and whether any input was truncated.

> Note: Every answer has an `action.actProbability` field. Its value is currently unreliable. Don't use it to trigger actions in an app.

> Note: To ask these questions about several texts, pass `states` instead of `state`. `decide()` then returns an array of results in the same order as `states`.
