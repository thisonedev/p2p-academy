Now that we've classified images, we're going to work with a much more unusual kind of input: brain-computer interface signals.

BCI models take a neural signal buffer and produce a text transcription that plugs into the same completion and event APIs the rest of the SDK uses. Loading a model, handing it input, and reading back a structured result works the same way it does for every other capability.
