In this lesson, we're going to generate the sound of heavy rain falling on a tin roof from a short text description, using a model called MOSS-SoundEffect.

MOSS-SoundEffect is packaged as a single Q8_0 file of about 3.5 GB that holds its text encoder, diffusion transformer and VAE. It runs on desktop only, and much faster on a GPU than on a CPU.

To load it, we pass `AUDIOGEN_MOSS_SFX_V2_Q8_0.src` as `modelSrc` and set three options in `modelConfig`:

- `ttsEngine: "moss-sfx"` - selects MOSS-SoundEffect.
- `useGPU: true` - runs inference on the GPU through Metal, CUDA, Vulkan or OpenCL, if the machine supports any of them.
- `seed` - sets the seed for the diffusion noise. The default is 0, which makes each description repeat its clip.

We set all three options as follows:

```ts
const modelId = await loadModel({
  modelSrc: AUDIOGEN_MOSS_SFX_V2_Q8_0.src,
  modelType: "tts-ggml",
  modelConfig: { ttsEngine: "moss-sfx", useGPU: true, seed: 42 },
});
console.log(`▸ Model loaded: ${modelId}`);
```

`textToSpeech()` takes the description as `text`, along with these settings:

- `stream: false` - collects the result in `result.buffer`.
- `seconds` - sets the length of the clip, up to 30 seconds.
- `steps` - sets the number of diffusion steps. The default is 100.

Each step denoises the full 30-second latent before the model crops the result to `seconds`, so a two-second clip takes about as long as a thirty-second one. Fewer `steps` run faster but lower the quality.

Our run uses 20 steps instead of the default 100 to generate two seconds of heavy rain on a tin roof:

```ts
const result = textToSpeech({
  modelId,
  text: "Heavy rain falling on a tin roof.",
  stream: false,
  seconds: 2,
  steps: 20,
});
```

MOSS-SoundEffect only outputs 48 kHz audio. Before saving the file, the code checks that generation finished and that the rate matches:

```ts
const samples = await result.buffer;
if (!(await result.done)) throw new Error("Sound-effect generation did not complete.");
const sampleRate = await result.sampleRate;
if (sampleRate !== 48000) throw new Error(`Unexpected sound-effect sample rate: ${sampleRate}`);
saveWav(samples, sampleRate, "output/text-to-speech/moss-sound-effect-output.wav");
```

`saveWav()` is already in the starting file. It writes the samples as a 16-bit mono WAV and logs the rate and length.

> Note: MOSS-SoundEffect is a batch engine. `textToSpeechStream()` and sentence streaming are not supported. With `stream: true`, the SDK returns the completed audio in one chunk.
