In this lesson, we're going to generate a dog barking twice in a quiet room and keep speech and music out of the clip, using a negative prompt in MOSS-SoundEffect.

The starting file already loads MOSS-SoundEffect and has the WAV writer. Besides `text`, `stream`, `seconds` and `steps`, `textToSpeech()` takes three more options for this model:

- `negativePrompt` - describes sounds to keep out of the clip.
- `guidance` - sets the classifier-free guidance scale, from 1 to 50. At 1, the model skips `negativePrompt`.
- `shift` - sets the flow-matching schedule shift, above 0 and up to 100.

If you leave out `guidance` and `shift`, MOSS-SoundEffect uses the defaults stored in its model file, which are 4 for `guidance` and 5 for `shift`.

Our code passes both values explicitly, along with the dog's description in `text` and the sounds to avoid in `negativePrompt`:

```ts
const result = textToSpeech({
  modelId,
  text: "A dog barking twice in a quiet room.",
  stream: false,
  seconds: 3,
  negativePrompt: "Speech, music, background voices.",
  steps: 20,
  guidance: 4,
  shift: 5,
});
```

The rest of the code checks the result and saves it to `moss-sound-effect-controls-output.wav`.
