CosyVoice3 is a text-to-speech engine built around a language model. Its output is 24 kHz audio, and it can change how the speech sounds without switching voices.

Each `textToSpeech()` run accepts one conditioning control for this, such as an emotion, a pace or an `instruct` request. This exercise asks for happy speech.

CosyVoice3 loads from a single registry constant: `TTS_COSYVOICE3_LLM_COSYVOICE_Q8_0`. That LLM GGUF belongs to a companion set, so loading it also downloads the flow and HiFT models, the tokenizer files and a baked voice. The model setup names that constant, the engine and a seed:

```ts
const modelId = await loadModel({
  modelSrc: TTS_COSYVOICE3_LLM_COSYVOICE_Q8_0,
  modelConfig: {
    ttsEngine: "cosyvoice3",
    seed: 42,
  },
});

console.log(`▸ Model loaded: ${modelId}`);
```

The full set is about 2.4 GB, which makes it the largest download in this chapter.

For `emotion`, the options are `anger`, `happy`, `neutral` and `sad`. `pace` is `slow` or `fast`, while `moderate` switches the pace channel off. `instruct` asks for a dialect, a volume or a style.

CosyVoice3 was trained on one instruction per synthesis, so the schema rejects options that engage two controls. Asking for happy speech at a fast pace fails, and you have to pick one. The example below sets an emotion:

```ts
const result = textToSpeech({
  modelId,
  text: "Hey, how are you doing today?",
  inputType: "text",
  stream: false,
  emotion: "happy",
});

const audioBuffer = Int16Array.from(await result.buffer);
const sampleRate = (await result.sampleRate) ?? COSYVOICE3_SAMPLE_RATE;
console.log(`▸ TTS complete. Total samples: ${audioBuffer.length}`);
console.log(`▸ Sample rate: ${sampleRate} Hz`);

fs.writeFileSync("output/text-to-speech/cosyvoice3-output.wav", createWav(audioBuffer, sampleRate));
console.log("▸ Saved output/text-to-speech/cosyvoice3-output.wav");
```

> Note: `instruct` takes an object with one of `dialect`, `volume` or `style`, such as `instruct: { volume: "soft" }`. Every `dialect` value names a Chinese variety such as `cantonese`, so pair it with text in that language.
