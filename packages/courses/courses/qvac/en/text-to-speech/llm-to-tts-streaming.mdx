So far, every engine in this chapter has received its full text in a single `textToSpeech()` run. With a streaming LLM, that means waiting for the whole answer before any audio plays. For this case, the SDK has a second function: `textToSpeechStream()`. It accepts text while the LLM is still producing it, so speech can start before the answer is finished.

`textToSpeechStream()` opens a duplex session. You write text into it and read audio back out. A single token is too short to speak on its own, so `accumulateSentences: true` makes the session wait for a full sentence before voicing it.

The starting file already loads Llama 3.2 1B and Supertonic, starts a streaming completion, and defines `filterChunk`, which removes `<think>` spans and markdown asterisks so the voice doesn't read them out. Opening the session takes the TTS model and that one sentence setting:

```ts
const ttsSession = await textToSpeechStream({
  modelId: ttsModelId,
  inputType: "text",
  accumulateSentences: true,
});
```

The reader starts before any text is written. Each response holds a sentence's PCM in `buffer` along with the rate the engine produced, so a reader that is already running collects each sentence while the LLM is still writing the rest of the answer:

```ts
const drainPcm = (async () => {
  for await (const m of ttsSession) {
    if (m.buffer.length === 0) continue;
    if (m.sampleRate !== undefined) sampleRate = m.sampleRate;
    appendPcmSamples(combinedPcm, m.buffer);
    phraseIndex += 1;
    console.log(`\n▸ [TTS phrase ${phraseIndex}] ${m.buffer.length} samples`);
  }
})();
```

With the reader in place, forward each cleaned token into the session. `end()` tells the session that no more text is coming, which lets it finish the last sentence and close the stream:

```ts
for await (const token of result.tokenStream) {
  const cleaned = filterChunk(token);
  if (cleaned.length > 0) {
    process.stdout.write(cleaned);
    ttsSession.write(cleaned);
  }
}
ttsSession.end();
await drainPcm;
```

Both models stay loaded for the whole answer, and together the two model files are about 900 MB. Audio also can't start until the LLM finishes its opening sentence, so a long one delays playback.

> Note: the session allows a single reader. Iterating `ttsSession` a second time throws `TextToSpeechStreamFailedError`, so collect everything you need inside the one `for await` loop.
