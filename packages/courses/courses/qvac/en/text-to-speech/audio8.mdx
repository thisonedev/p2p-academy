Now that Parler can steer delivery with an emotion label, it's time to try Audio8. This multilingual engine produces speech the way an LLM produces text.

Audio8 splits synthesis across two GGUF files, so one `loadModel()` has to bring in both. The language model in the top-level `modelSrc` samples codec frames that each cover 46 ms of audio. Those frames aren't playable audio yet, so the decoder in `modelConfig.audio8CodecDecoderModelSrc` turns them into a 44.1 kHz waveform.

Since the language model samples every frame, `temperature`, `topP` and `seed` in `modelConfig` tune that sampling. The first two vary the delivery much as they vary an LLM's word choice, and `seed` pins the randomness so a rerun produces identical audio. Loading both files together looks like this:

```ts
const modelId = await loadModel({
  modelSrc: TTS_LM_MULTILINGUAL_AUDIO8_Q8_0,
  modelConfig: {
    ttsEngine: "audio8",
    audio8CodecDecoderModelSrc: TTS_CODEC_DECODER_AUDIO8_Q8_0,
    temperature: 0.7,
    topP: 0.9,
    seed: 42,
  },
});

console.log(`▸ Model loaded: ${modelId}`);
```

The first run downloads about 1 GB for the Q8 language model and decoder. That's roughly eight times the size of the Supertonic model from the first lesson.

Synthesis still runs through `textToSpeech()`, as it did for the earlier engines. The difference is that you await `result.sampleRate` and fall back to `AUDIO8_SAMPLE_RATE` only when that promise resolves to `undefined`:

```ts
const result = textToSpeech({
  modelId,
  text: "Hey, how are you doing today?",
  inputType: "text",
  stream: false,
});

const audioBuffer = Int16Array.from(await result.buffer);
const sampleRate = (await result.sampleRate) ?? AUDIO8_SAMPLE_RATE;
console.log(`▸ TTS complete. Total samples: ${audioBuffer.length}`);
console.log(`▸ Sample rate: ${sampleRate} Hz`);
```

Audio8 defaults to 44.1 kHz, but setting `outputSampleRate` at load time or turning on the LavaSR enhancer changes that number. A WAV header written with the wrong value plays the audio too fast or too slow.

Once you have `sampleRate`, pass it to the `createWav()` helper at the bottom of your starting file and save the result:

```ts
fs.writeFileSync("output/text-to-speech/audio8-output.wav", createWav(audioBuffer, sampleRate));
console.log("▸ Saved output/text-to-speech/audio8-output.wav");
```

> Note: Audio8 can clone a voice too. Cloning needs a third file in `audio8CodecEncoderModelSrc`. It also needs `referenceAudioSrc` and `referenceText` in `modelConfig`, and the reference text has to be the exact transcript of the recording.
