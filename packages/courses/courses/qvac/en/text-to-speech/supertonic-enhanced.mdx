The LavaSR enhancer has a smaller companion: a denoiser that cleans the synthesized signal first. Together they turn Supertonic's 44.1 kHz output into cleaned-up 48 kHz audio.

Both models are optional `modelConfig` fields with no on/off flag, so passing a GGUF turns each one on. First the denoiser cleans the signal and keeps the sample rate as it is, then the enhancer extends it to 48 kHz.

The denoiser has to see the whole utterance at once, so it can't work on an engine that sends audio out in chunks while it's still synthesizing. Supertonic always produces the full clip in one go, so the pair works with it every time. Adding both to the Supertonic setup looks like this:

```ts
const modelId = await loadModel({
  modelSrc: TTS_MULTILINGUAL_SUPERTONIC3_Q8_0,
  modelConfig: {
    ttsEngine: "supertonic",
    language: "en",
    voice: "F1",
    lavasrDenoiserModelSrc: TTS_DENOISER_LAVASR_FP16.src,
    lavasrEnhancerModelSrc: TTS_ENHANCER_LAVASR_FP16.src,
  },
});

console.log(`▸ Model loaded: ${modelId}`);
```

The FP16 denoiser is about 0.5 MB to download, but it adds a processing pass to every clip.

The enhancer runs last, so the rate the engine reports is 48 kHz:

```ts
const result = textToSpeech({
  modelId,
  text: "Supported JS environments include Bare, Node.js, Expo and Bun.",
  inputType: "text",
  stream: false,
});

const audioBuffer = Int16Array.from(await result.buffer);
const sampleRate = (await result.sampleRate) ?? ENHANCED_SAMPLE_RATE;
console.log(`▸ TTS complete. Total samples: ${audioBuffer.length}`);
console.log(`▸ Sample rate: ${sampleRate} Hz`);

fs.writeFileSync("output/text-to-speech/supertonic-enhanced-output.wav", createWav(audioBuffer, sampleRate));
console.log("▸ Saved output/text-to-speech/supertonic-enhanced-output.wav");
```

> Note: Chatterbox, Parler and CosyVoice3 accept the denoiser too, as long as native streaming is off. A Chatterbox load with `streamChunkTokens` above 0 rejects `lavasrDenoiserModelSrc`.
