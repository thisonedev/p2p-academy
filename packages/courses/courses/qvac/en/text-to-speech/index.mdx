Now that we can turn speech into text, we're going to turn text back into speech.

Text-to-speech takes a string and returns audio samples. Supertonic covers English with a fast single-file engine. Chatterbox layers voice cloning on top: feed it a reference WAV and it reads new text in that voice. Supertonic 3 covers 31 languages from a single multilingual GGUF. And `textToSpeech({ stream: true })` exposes `bufferStream` for incremental audio output, which is what you want for low-latency voice.
