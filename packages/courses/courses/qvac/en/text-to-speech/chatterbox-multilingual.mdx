In this lesson, we're going to load multilingual Chatterbox and synthesize Japanese speech.

The turbo checkpoint covers English only. A second T3 and S3Gen pair handles 23 languages. You choose one with the `language` field in `modelConfig`.

For most languages, setting `language` is enough. Japanese is written without spaces between words, so the engine first splits each sentence into words with the MeCab/IPAdic dictionary that `mecabDictSrc` points to. The schema rejects `language: "ja"` without it. For Japanese, the model setup looks like this:

```ts
const modelId = await loadModel({
  modelSrc: TTS_T3_MULTILINGUAL_CHATTERBOX_Q4_0,
  modelConfig: {
    ttsEngine: "chatterbox",
    language: "ja",
    s3genModelSrc: TTS_S3GEN_MULTILINGUAL_CHATTERBOX_Q4_0,
    mecabDictSrc: TTS_MECAB_IPADIC_CHATTERBOX,
    cfmSteps: 1,
    threads: 8,
  },
});

console.log(`▸ Model loaded: ${modelId}`);
```

The multilingual pair is Q4, so it stores its weights at lower precision than the Q8 English checkpoint. That keeps the download to about 1.1 GB.

With the model loaded, `textToSpeech()` takes the Japanese text as written, with no romanization step in your code:

```ts
const result = textToSpeech({
  modelId,
  text: "こんにちは。これはQVAC SDKを使った日本語音声合成のテストです。",
  inputType: "text",
  stream: false,
});

const audioBuffer = Int16Array.from(await result.buffer);
const sampleRate = (await result.sampleRate) ?? CHATTERBOX_SAMPLE_RATE;
console.log(`▸ TTS complete. Total samples: ${audioBuffer.length}`);
console.log(`▸ Sample rate: ${sampleRate} Hz`);

fs.writeFileSync("output/text-to-speech/chatterbox-multilingual-output.wav", createWav(audioBuffer, sampleRate));
console.log("▸ Saved output/text-to-speech/chatterbox-multilingual-output.wav");
```

> Note: Chinese has a requirement of its own. `language: "zh"` needs a Cangjie table in `cangjieTsvSrc`, which the engine uses for romanization.
