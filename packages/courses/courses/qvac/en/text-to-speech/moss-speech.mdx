So far in this chapter, `textToSpeech()` has turned our text into speech word for word. MOSS-Speech treats the text as a question instead and generates an answer of its own. It also accepts a recording as input and can reply aloud or in writing.

It's a 9B language model paired with a codec. The Q8_0 checkpoint and the codec add up to about 11 GB. MOSS-Speech is a desktop engine. The SDK examples recommend a GPU with enough memory for both files.

By default, MOSS-Speech speaks its answer. With `textReply: true`, `textToSpeech()` returns it as text in `result.text` and leaves the audio buffer empty.

We pass the language model as `modelSrc` and the codec as `mossSpeechCodecModelSrc`. `modelConfig` takes two more settings:

- `useGPU: true` - moves inference to the GPU through Metal, CUDA, Vulkan or OpenCL, whichever the machine supports.
- `seed` - sets the RNG seed, which makes sampled replies reproducible.

We put MOSS-Speech on the GPU and set its seed:

```ts
const modelId = await loadModel({
  modelSrc: TTS_MOSS_SPEECH_Q8_0,
  modelType: "tts-ggml",
  modelConfig: {
    ttsEngine: "moss-speech",
    mossSpeechCodecModelSrc: TTS_CODEC_MOSS_SPEECH_F16,
    useGPU: true,
    seed: 42,
  },
});
console.log(`▸ Model loaded: ${modelId}`);
```

`textToSpeech()` takes the question as `text`, along with these settings:

- `stream: false` - collects the result in `result.buffer`.
- `textReply: true` - asks for a text-only reply.
- `greedy: true` - switches from sampling to greedy decoding.
- `maxNewTokens` - caps the reply at 128 generated tokens. Without it, MOSS-Speech uses the context left after the prompt.
- `maxReplySeconds` - cuts a spoken reply after that many seconds.
- `systemPrompt` - replaces the model's default system turn.

We ask MOSS-Speech for a short text reply like so:

```ts
const result = textToSpeech({
  modelId,
  text: "What is two plus two? Answer in one short sentence.",
  stream: false,
  textReply: true,
  greedy: true,
  maxNewTokens: 128,
  maxReplySeconds: 5,
  systemPrompt: "You are a helpful assistant. Give short, direct answers.",
});
```

We read the answer from `result.text`. The second log line shows the length of the audio buffer, which is zero for a text reply:

```ts
const samples = await result.buffer;
const reply = await result.text;
console.log(`▸ Reply: ${reply?.trim()}`);
console.log(`▸ Audio samples: ${samples.length}`);
```

> Note: MOSS-Speech is a batch engine. `textToSpeechStream()` and sentence streaming are not supported. With `stream: true`, the SDK returns the completed audio in one chunk.

> Note: `assessModelFit()` has no native fitter for MOSS-Speech in this release. It can't confirm that the model fits before the download.
